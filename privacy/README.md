# 공유한 순간 — 프라이버시 선택 게임 (`/privacy/`)

중·고등학생이 학급 축제를 준비하는 나흘 동안 단톡방·SNS·AI 도우미·공용 PC에서 마주치는 프라이버시 문제를 **선택의 누적**으로 경험하는 웹 게임입니다. 정답·오답을 표시하지 않고, 앞선 선택이 뒤의 대화·선택지·결말로 돌아옵니다.

> 핵심 질문: 누가, 누구의 정보를, 누구에게, 어떤 목적으로, 어디까지 공유할 수 있는가?

- 대상: 중학생·고등학생 / 개인 플레이 후 교실 토론 / 첫 플레이 약 15~20분(목표치, 실측 전)
- 구성: 프롤로그 → 1~3장(사건 9개) → 에필로그 → 엔딩 → 선택 경로 → 성찰 질문
- 서버·로그인·외부 API·분석 도구 없음. 게임 속 이름·번호·계좌·학교는 모두 허구.

## 실행

정적 파일이므로 아무 정적 서버로 저장소 루트를 열고 `/privacy/`에 접속합니다.

```bash
node privacy/tests/serve.mjs 8080      # → http://127.0.0.1:8080/privacy/
```

`index.html`을 파일로 직접 열어도(`file://`) 실행됩니다(ES 모듈을 쓰지 않음). 다만 `file://`에서는 브라우저에 따라 저장이 막힐 수 있고, 그때는 메모리로만 진행하며 안내가 뜹니다.

## 파일 구조

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 6종(시작·본편·장 전환·엔딩·선택 경로·성찰) + 메뉴·확인 창 |
| `css/style.css` | 스타일(미스트+틸, 375px 대응, 포커스 링, 움직임 줄이기) |
| `js/story.js` | **스토리 데이터** — 장면·대사·선택지·조건·사건별 결과·엔딩·성찰 질문. 대사 수정은 이 파일만 |
| `js/engine.js` | 상태 엔진(조건 판정·선택·진행·되돌리기·엔딩 판정). DOM을 모르는 순수 로직, Node에서도 동작 |
| `js/storage.js` | 저장 래퍼(localStorage 실패·손상 시 메모리로 계속) |
| `js/config.js` | 공통 캐릭터 코드 → 이미지 매핑(현재 비어 있음) |
| `js/app.js` | 화면 그리기·입력 처리 |
| `assets/avatar-default.svg` | **임시 아바타**(팀 공식 캐릭터 아님) |
| `tests/` | 검증 도구(아래). 게임 실행에는 쓰이지 않음 |

스토리 작성법(대사 `"hayun: 안녕"`, 조건 `'e2post=group|story'`, `'trust.seoa<0'` 등)은 `js/story.js` 맨 위 주석에 정리되어 있습니다.

## 저장 키와 팀 공통 연동

| 키 | 읽기/쓰기 | 내용 |
|---|---|---|
| `ethicity.player` | **읽기만** | `{"character":"char_03","nickname":"…"}` — 없음·손상·형식 오류면 기본 아바타 + ‘플레이어’. 절대 덮어쓰지 않음 |
| `ethicity.result.privacy` | 엔딩 도달 시 쓰기 | `{"game":"privacy","completed":true,"ending":"B","card":"…"}` — 다시 완료하면 최근 결과로 갱신, 재시작만으로는 지우지 않음 |
| `ethicity.privacy.progress.v1` | 이 게임 전용 | `{ v:1, run:{현재 장면·상태·선택 기록}, explored:{장면:[고른 선택지]}, endingsSeen:[…] }` |
| `ethicity.privacy.settings.v1` | 이 게임 전용 | 대사 속도·움직임 줄이기 |

- **`card` 임시 가정**: 저장소에 `card`의 팀 공통 정의가 없어서(2026-10-17 확인) 결과 요약 문자열을 넣습니다. 예: `공유한 순간 · 엔딩 B 「멈춘 확산, 남은 과제」 — 문제가 생겼지만, 확산을 줄이고 회복을 시작했다.` 공통 형식이 정해지면 `js/app.js`의 `cardText()`만 바꾸면 됩니다.
- **공통 캐릭터 이미지**: 저장소에 공통 캐릭터 이미지·매핑이 아직 없습니다. 정해지면 `js/config.js`의 `characterImages`에 `'char_03': '../경로/char_03.png'` 형태로 추가합니다. 매핑이 없는 코드는 임시 아바타로 표시하고 대체 텍스트도 ‘임시 아바타’로 둡니다.
- 별명은 항상 `textContent`로만 표시합니다(HTML로 해석하지 않음).
- 메뉴의 ‘이 게임 기록 지우기’는 `ethicity.privacy.progress.v1`과 `ethicity.result.privacy`만 지웁니다. 공통 플레이어 정보와 다른 게임 키는 건드리지 않습니다.
- localStorage는 **같은 출처(origin)** 안에서만 공유됩니다. 다른 게임과 결과를 공유하려면 같은 도메인에 배포해야 합니다. 출처 간 전송 기능은 넣지 않았습니다.

| 장 | 사건 | 이전 선택이 남는 예 |
|---|---|---|
| 1 우리끼리인데 뭐 어때? | 계좌번호 정산 · 잠든 친구 사진(촬영 동의 ≠ 게시 동의) · 고민 대화 캡처 | 캡처를 보냈다면 ‘두 번째 전달’ 장면과 재전송 중단 선택이 나옴 |

| 3 공유 버튼 뒤의 사람 | 낯선 사람에게 번호 장난 · “직접 보자” 만남 제안 · 신상 정리 스토리 | 공용 PC에서 도현을 도왔다면(신뢰↑) 도현이 장난을 멈춤 / 1장에서 학교 태그 스토리를 올렸다면 다툼 상대가 학교를 알아냄 |

### 엔딩 판정 (위에서부터 처음 맞는 하나)

| 코드 | 제목 | 조건 |
|---|---|---|
| D | 혼자서는 풀리지 않는 일 | 약속 장소에 혼자 나감 **또는** 현실의 안전 위협 상황 3회 이상 |
| A | 함께 세운 경계 | 필요 이상 확산 ≤ 1 **그리고** 당사자 뜻을 물은 횟수 ≥ 3 |
| B | 멈춘 확산, 남은 과제 | 수습 행동 + 도움 연결 ≥ 3 |
| C | 삭제 이후에도 | 그 밖의 모든 경우(기본값) |

수치(`spread`·`consent`·`minimize`·`repair`·`help`·`serious`, 인물별 신뢰)는 하나의 점수·등급으로 합치지 않습니다. 장 전환·엔딩 화면에는 항목별 변화량·횟수와 인물별 관계(가까워짐·그대로·멀어짐), 사건별 결과 문장으로만 보여 줍니다. 엔딩 화면에는 “엔딩은 성격이나 등급이 아니다”라는 안내가 붙습니다.

### 엔딩별 도달 경로 예시 (`tests/routes.js`)

- **A**: 사진 담당 → 계좌는 개인톡으로 보내자고 제안 → 찍기 전 민준에게 물음, 올리지 않음 → 서아에게 먼저 물음 → 합성 이미지에 “하윤이 잘못 아니야” → 하윤 뜻 묻고 함께 신고 → AI엔 부스 정보만 → 공용 PC 로그아웃 후 알림 → 번호 장난 말림 → 보호자에게 알림 → 서아 뜻 묻기 → 사람 찾기 멈추자
- **B**: 단톡방에 계좌 올림 → 내 것부터 지움 → 잠든 사진 반톡에 올림 → 삭제·사과·저장본 삭제 요청 → … 신고·삭제 요청·선생님께 알리기로 수습
- **C**: 계좌 공개 후 방치 → 사진 반톡 → 삭제 요청 무시 → 고민 캡처 전달 후 방치 → 하윤 탓 → 아무 말 하지 않기 …
- **D**: … 합성 이미지 전달 → 번호 장난 참여 → 학교·시간을 알려 주고 혼자 나감

## 검증

```bash
node privacy/tests/check-story.mjs     # 스토리 그래프(1~2분)
node privacy/tests/run-probes.mjs      # 헤드리스 Edge로 실제 화면 플레이(15개 시나리오)
```

- `check-story.mjs`: 없는 장면·인물·플래그 참조, 막다른 장면, 사건을 건너뛰는 길(정적), 서로 다른 완주 경로 수(정확 계산), 무작위 완주 10만 회로 모든 장면·선택지·조건부 대사·사건 결과 문장의 등장 여부, 엔딩별 대표 경로 도착.
- `run-probes.mjs`: `serve.mjs`가 `?probe=` 요청에만 `tests/probe-pre.js`·`probe-post.js`를 끼워 넣어(원본 파일 변경 없음) 버튼을 실제로 눌러 플레이합니다. 엔딩 A~D 완주(B는 숫자 키 조작), 공통 캐릭터 없음·손상·형식 오류, HTML이 든 긴 별명, 새로고침 후 이어 하기, 되돌리기(취소·확인), 저장소 차단, 손상·옛 진행 기록, 기록 지우기(다른 게임 키 보존), 다시 하기(결과·해금 유지), 대사 순차 표시·Esc 메뉴 닫기, `/privacy` → `/privacy/` 이동, 콘솔 오류.
- Edge 경로가 다르면 `EDGE` 환경 변수로 지정합니다. 375px 화면은 `tests/mobile.html`(iframe 3개)을 스크린샷으로 확인합니다.

## 남은 확인 사항

- 팀 공통 `card` 형식, 공통 캐릭터 이미지·코드 매핑(현재 임시 아바타).
- 배포 방식(GitHub Pages 등)과 공통 진입 페이지에서 `/privacy/`로의 링크.
- 실제 학생 플레이 시간 측정(15~20분 목표는 추정치), 교사 검토(대사 수위·사실 표현).
- 본문 폰트 Pretendard는 CDN에서 불러옵니다. 오프라인이면 시스템 한글 글꼴로 대체됩니다.
