# 공유한 순간 — 프라이버시 선택 게임 (`/privacy/`)

중·고등학생이 학급 축제를 준비하는 나흘 동안 단톡방·SNS·AI 도우미·공용 PC에서 마주치는 프라이버시 문제를 **선택의 누적**으로 경험하는 웹 게임입니다. 정답·오답을 표시하지 않고, 앞선 선택이 뒤의 대화·선택지·결말로 돌아옵니다.

> 핵심 질문: 누가, 누구의 정보를, 누구에게, 어떤 목적으로, 어디까지 공유할 수 있는가?

- 대상: 중학생·고등학생 / 개인 플레이 후 교실 토론 / 첫 플레이 약 15~20분(목표치, 실측 전)
- 구성: 프롤로그 → 1~3장(사건 9개) → 에필로그 → 엔딩 → 선택 경로 → 성찰 질문
- **처음부터 끝까지 맵 위에서** 진행한다(포켓몬식). 아침에 내 방에서 일어나 교실까지 걸어가는 **등교 오프닝**으로 시작하고, 사건 사이에는 다음 장소(❗)까지 걷는다. 하교·귀가는 교문 → 마을 길 → 우리 집까지 직접 걷는다.
- 모든 장면은 맵 위 한 장소에서 벌어진다. 단톡·개인톡·SNS는 **폰**, 공용 PC·AI 도우미는 **모니터**로 그 장소 위에 떠오르고, 그 자리 대화는 아래 **대화창**에 한 줄씩 나온다. 같은 공간 친구는 머리 위 말풍선으로 반응한다(폰 메시지는 원문 대신 📱…).
- 서버·로그인·외부 API·분석 도구 없음. 게임 속 이름·번호·계좌·학교는 모두 허구.

## 실행

정적 파일이므로 아무 정적 서버로 저장소 루트를 열고 `/privacy/`에 접속합니다.

```bash
node privacy/tests/serve.mjs 8080      # → http://127.0.0.1:8080/privacy/
```

`index.html`을 파일로 직접 열어도(`file://`) 실행됩니다(ES 모듈을 쓰지 않음). 다만 `file://`에서는 브라우저에 따라 저장이 막힐 수 있고, 그때는 메모리로만 진행하며 안내가 뜹니다.

## 저장 키와 팀 공통 연동

| 키 | 읽기/쓰기 | 내용 |
|---|---|---|
| `ethicity.player` | **읽기만** | `{"character":"char_03","nickname":"…"}` — 없음·손상·형식 오류면 기본 아바타 + ‘플레이어’. 절대 덮어쓰지 않음 |
| `ethicity.result.privacy` | 엔딩 도달 시 쓰기 | `{"game":"privacy","completed":true,"ending":"B","card":"…"}` — 다시 완료하면 최근 결과로 갱신, 재시작만으로는 지우지 않음 |
| `ethicity.privacy.progress.v1` | 이 게임 전용 | `{ v:1, run:{현재 장면·상태·선택 기록}, explored:{장면:[고른 선택지]}, endingsSeen:[…] }` |
| `ethicity.privacy.settings.v1` | 이 게임 전용 | 대사 속도·움직임 줄이기 |

- **`card` 임시 가정**: 저장소에 `card`의 팀 공통 정의가 없어서(2026-10-17 확인) 결과 요약 문자열을 넣습니다. 예: `공유한 순간 · 엔딩 B 「멈춘 확산, 남은 과제」 — 문제가 생겼지만, 확산을 줄이고 회복을 시작했다.` 공통 형식이 정해지면 `js/app.js`의 `cardText()`만 바꾸면 됩니다.
- **공통 캐릭터 이미지**: 저장소에 공통 캐릭터 이미지·매핑이 아직 없습니다. 정해지면 `js/config.js`의 `characterImages`에 `'char_03': '../경로/char_03.png'` 형태로 추가합니다. 매핑이 없는 코드는 임시 아바타로 표시하고 대체 텍스트도 ‘임시 아바타’로 둡니다.
- 별명은 항상 `textContent`로만 표시합니다(HTML로 해석하지 않음).
- 메뉴의 ‘이 게임 기록 지우기’는 `ethicity.privacy.progress.v1`과 `ethicity.result.privacy`만 지웁니다. 공통 플레이어 정보와 다른 게임 키는 건드리지 않습니다.
- localStorage는 **같은 출처(origin)** 안에서만 공유됩니다. 다른 게임과 결과를 공유하려면 같은 도메인에 배포해야 합니다. 출처 간 전송 기능은 넣지 않았습니다.

## 맵

- 맵 한 장(48×23칸): 2학년 3반 교실·복도·도서관 / 매점 앞·운동장 축제 부스 / 교문 / 마을 길 / 우리 집 → 내 방(문으로 이동).
- 흐름: 걷기(‘지금 할 일’과 ❗) → 걸어가서 말 걸기·조사 → **그 장소 무대 위에서 장면**(폰·모니터·대화창) → 다음 걷기. 장면 장소가 걷기와 다르면 짧은 시간 카드(예: ‘그날 밤 · 내 방’) 뒤 옮겨 간다.
- 첫날 아침은 내 방에서 시작해 직접 등교(오프닝). 이후 다음 날 아침은 ‘다음 날’ 카드 뒤 **교문 앞**에서 시작, 하교는 직접 걷기. 모든 걷기 구간은 시작 위치(spawn)가 정해져 있다.

| 걷기 | 장소 | ❗ 대상 |
|---|---|---|
| 오프닝(등교) | 내 방 → 교실 | 하윤(반 친구 소개) |
| ① 정산 | 교실 → 내 방(하교) | 침대 |
| ② 잠든 사진 | 교실 | 민준(엎드려 잠듦) |
| ③ 고민 | 내 방 | 침대 |
| ④ 합성 이미지 | 매점 앞 | 도현 |
| ⑤ AI 도우미 | 내 방 | 내 책상 컴퓨터 |
| ⑥ 공용 PC | 도서관 | 공용 PC 3번 |
| ⑦ 번호 장난 | 운동장 부스 | 도현 |
| ⑧ “직접 보자” | 내 방 | 내 책상 컴퓨터 |
| ⑨ 신상 스토리 | 교실 | 하윤 |
| 에필로그 | 교실 | 담임 선생님 |

- 조작: 방향키·WASD 이동, Space·Enter 말 걸기·조사 / 화면을 누르면 그 칸까지 걸어감(인물·사물을 누르면 가서 말 걸기) / **‘목적지로 바로 가기’** 버튼(걷기가 어려운 학생·시간 부족 대비).
- ❗가 아닌 인물에게 말 걸면 앞선 선택에 따라 달라지는 한 줄 대사(`world.js`의 `IDLE`), 사물은 조사 문구.
- 맵 위치는 진행 저장(`progress.pos`)에 함께 저장되어, 새로고침해도 같은 자리에서 이어 걷는다.
- **장면 무대** (`world.js` `STAGES`): 26장면마다 장소·시간대·같은 공간 인물·컷 카드 문구·반응 말풍선(`bubbles: [{ on: 그 줄의 글자, who, text }]`). `check-story.mjs`가 인물 위치와 말풍선 기준 줄을 검사한다.
- **새로 쓴 대사(교사 검토 대상)**: 오프닝 하윤의 반 친구 소개·길목 자기소개(`TRIGGERS.pro_1`의 `greet`·`castLines`), 하교 한 줄(`c1_e1_a`의 `greet`), 장면 컷 카드 문구·반응 말풍선(`STAGES`). 스토리 본문(`story.js`)은 그대로다.
- **주인공 모습(남·여)**: 공통 캐릭터 코드가 `js/config.js`의 `playerLooks`에 매핑돼 있으면 그 모습을 쓰고, 없으면 시작 화면의 **두 주인공 카드**(메인 비주얼)에서 학생이 고른다(이 게임 설정 `ethicity.privacy.settings.v1`에만 저장, 공통 정보는 건드리지 않음). 고르기 전에는 시작하지 않는다.
- **관계 보고**: 장이 끝날 때·엔딩의 ‘친구들과의 사이’ 줄마다 오른쪽 끝에 그 친구 얼굴(캐릭터 시트에서 머리만 잘라 2배)과 ♥/–/💧 표식.
- **그림 교체**: `assets/sprites/char_<id>.png`(id: hayun·dohyun·seoa·minjun·teacher·friend·player_m·player_f — 48×72 칸, 가로 4프레임 × 세로 아래·왼·오·위), `minjun_sleep.png`를 넣으면 자동으로 그 그림을 쓴다. 없으면 임시 도형(원+머리글자+이름표). 타일·가구는 `tiles.png`+`tiles.json`(48px 격자, 34종)을 읽어 그린다(`file://`에선 `js/map.js`의 내장 좌표 사용). 칸 크기는 시트에서 자동 인식하고 화면에는 정수배(1배·2배)로만 그려 도트가 뭉개지지 않는다.
- **현재 그림**: Codex 납품 v2(48×72 캐릭터 8장·타일 34종, 내장 이미지 생성으로 새로 그림 — `example/sprite-delivery-v2/`에 원본·검증 기록, 팀 레포엔 올리지 않음). 공용 PC 그림에 ‘3’이 찍혀 있어 1·2번은 코드로 번호를 덧씌운다(번호 없는 PC 그림을 받으면 제거 가능).

## 남은 확인 사항

- 팀 공통 `card` 형식, 공통 캐릭터 이미지·코드 매핑(현재 임시 아바타).
- 맵이 화면의 중심이 되고 등교 오프닝이 더해져 플레이 시간이 늘었다(최단 이동 약 340칸 + 장면 컷 카드) — 실측 필요.
- 타이틀 일러스트 2장이 각 약 1.5MB — 휴대폰 첫 로딩이 느리면 줄인 사본(webp 등)으로 교체 검토.
- 포즈 그림(고개 숙임·폰 내밀기 등)은 아직 없어 방향·말풍선으로만 연출 — 필요하면 Codex에 요청.
- 배포 방식(GitHub Pages 등)과 공통 진입 페이지에서 `/privacy/`로의 링크.
- 실제 학생 플레이 시간 측정(15~20분 목표는 추정치), 교사 검토(대사 수위·사실 표현).
- 본문 폰트 Pretendard는 CDN에서 불러옵니다. 오프라인이면 시스템 한글 글꼴로 대체됩니다.
