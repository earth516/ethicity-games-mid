# 야외 바닥 (2026-10-18)

- `grass.png`: 새로 생성한 초록 잔디 텍스처.
- `path.png`: 새로 생성한 밝은 흙길 텍스처.
- `../../js/terrain.js`: 원본 이미지를 8×8타일 크기로 사용하고 반사 반복하여 연속 바닥 캐시를 만든다. 기존 48px atlas의 바닥은 야외에서만 대체한다.
- 길의 바깥 모서리는 인접 타일에 맞춰 둥글게 처리하며 경계에 작은 풀을 그린다. 충돌·이동·문·사건 데이터는 변경하지 않는다.
- 새 이미지는 `PrivacyPalette` 색상 보정을 적용하지 않는다. 원본 파일을 동일 이름으로 교체하면 새로고침 후 반영된다. 브라우저 캐시가 남으면 Ctrl+F5. 배포 사이트는 별도 push/배포 필요.
- 생성 이미지 로딩 실패 시 기존 아틀라스 바닥으로 돌아간다.

## 검증

Playwright의 격리된 Edge로 실제 `/privacy/` 로딩, 집 앞 저장 위치에서 이어 하기, 1200×900 및 390×844 캡처를 확인했다. 해당 경로 pageerror 0. JS 구문 검사 통과. 기존 dump-dom 기반 프로브는 Edge가 DOM을 반환하지 않아 실행 결과를 확인할 수 없었다. 전체 이야기 회귀 검증은 이번 변경에서 수행하지 않았다.

재현: Playwright가 설치된 환경에서 `node privacy/tests/terrain-browser-check.cjs`. 필요하면 PLAYWRIGHT_PATH 환경변수로 설치 경로를 지정한다. 캡처는 tests/_shot-terrain.png 및 _shot-terrain-mobile.png(ignored)에 저장한다. 기존 사용자 브라우저 저장소는 접근하지 않는다.

## 범위

후속 작업으로 나무·물·야외 벤치·가로등도 교체했다(../outdoor/README.md 참고). 실내 바닥·가구는 기존 소재다. 이번 변경은 로컬 적용이며 원격 배포하지 않았다.
