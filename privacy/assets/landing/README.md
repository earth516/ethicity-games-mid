## Claude Code 연결 요청
시작 화면의 남/여 선택 영역에 이 두 이미지를 같은 비중으로 배치한다. 모바일에서는 나란히 놓거나 높이를 줄여 첫 조작 버튼이 지나치게 아래로 밀리지 않게 한다. 이름은 학생이 선택할 주인공이며, 아직 팀 공식 공통 캐릭터 코드 매핑을 임의로 만들지 않는다.

- 투명 PNG. 밝은 미스트/하늘색 계열 배경 위 사용 권장.
- 세로 크기 약 320~460 CSS px부터 비교. 두 이미지의 보이는 머리·발 높이를 맞추고 얼굴/신발을 자르지 않는다.
- `object-fit: contain` 사용. 고해상도 일러스트이므로 `image-rendering: pixelated` 및 맵 전용 `palette.js`를 적용하지 않는다.
- 선택 상태는 이미지 변색 대신 카드 테두리·체크·라디오로 표시. 기본 선택 없음 및 키보드 선택을 유지한다.
- 공통 player 정보는 덮어쓰지 않고 기존 privacy 전용 선택 저장을 유지한다.
- 이번 납품은 이미지와 설명만이다. 랜딩 화면 구현/실제 배치 검증은 아직 하지 않았다.

제작 방향: 두 주인공 모두 활기차고 친근한 전신 게임 일러스트, 선명한 파란 후드와 노란 가방, 밝은 표정과 자연스러운 스마트폰 포즈, 남색 선화와 셀 명암. 기존 픽셀 시트는 인물 식별 기준으로만 참조하며 랜딩 이미지는 비픽셀 일러스트로 제작.
