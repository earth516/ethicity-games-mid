# 탐험 UI 아이콘

내장 ImageGen으로 새로 생성. 공통 제작 사양: 아이보리 말풍선, 남색 계단형 도트 테두리, 짧은 아래쪽 꼬리, 제한된 색상과 큰 심볼, 투명 배경. 32~48px 화면 표시용.

| 파일 | 심볼 | 용도/연결 상태 |
|---|---|---|
| quest.png | 노란 느낌표 | map.js의 다음 사건 표시. 기존 빨간 원을 대체 |
| talk.png | 초록 점 3개 | 대화 가능 표시용 자산. 현재 자동 표시하지 않음 |
| inspect.png | 파란 렌즈의 돋보기 | 조사 가능 표시용 자산. 현재 자동 표시하지 않음 |
| complete.png | 초록 체크 | 완료 표시용 자산. 현재 자동 표시하지 않음 |

느낌표는 진행할 사건 한 곳에만 표시한다. 남은 아이콘은 Claude Code가 실제 상호작용 상태와 연결할 때 사용한다. 퀘스트 아이콘은 이미지 로딩 실패 시 아이보리/남색 문자 표시로 대체한다. 화면 가장자리에서도 아이콘이 잘리지 않도록 위치를 제한한다.

원본은 고해상도 PNG이며 캐릭터 시트가 아니다. 보정용 palette.js를 통과시키지 않는다. 이미지 비율/투명 영역을 고려해 축소해서 사용한다. 게임 실행 시의 가독성과 캐릭터 머리 겹침은 최종 연결 화면에서 확인해야 한다.
