# 학교 리뉴얼 · 2026-10-18

## 소재와 연결

- exterior.png: 중앙 현관과 지붕을 포함한 학교 전체 외관.
- desk.png, teacher-desk.png, locker.png, bookcase.png, pc.png: 교실·도서관 가구.
- board.png, window.png: 벽 부착물.
- wood.png: 연속해서 사용하는 참나무 바닥.
- `js/school.js`: 소재 로드, 투명 여백 제외, 벽·문·복도와 안내판 그리기. 원본 PNG/기존 atlas 보존, 색상 보정 중복 적용 없음.
- `js/map.js`: 학교 밖에서는 외관을 표시하고 학교 안의 가구·NPC·말풍선을 숨긴다. 학교 내부 목표 표시는 현관으로 옮긴다. 바깥에서 학교를 클릭하면 현관으로 걸어간다.

## 지붕 규칙

현재 학교 범위는 x=0..21, y=0..10. 플레이어가 범위 밖이면 지붕이 보이고, 현관 (10/11,10)을 통해 들어가면 내부로 전환한다. 기존 이동·충돌·사건 데이터와 문 좌표를 유지한다. 외관 로딩 실패 시에도 불투명 대체 건물로 내부를 가린다. 건물 크기 변경 시 school.js의 contains/exterior와 map.js 현관 안내 좌표를 함께 수정한다.

## 검증

`tests/school-browser-check.cjs`: 격리된 Playwright Edge에서 실제 키보드 출입, 지붕 재표시, 바깥 가구 미표시, 교실·도서관 새 소재 표시를 확인. 1200×900 및 390×844 캡처. 해당 실행 pageerror 0.

스토리 검사: SAMPLES=2000으로 전 장면·조건부 선택·사건 연결 및 엔딩 A~D 대표 경로, 맵 목적지 도달 검사 통과. 변경은 로컬이며 push·배포하지 않았다.
