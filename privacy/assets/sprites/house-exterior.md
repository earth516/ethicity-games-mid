# 집 외관

- 생성: 2026-10-18, 내장 ImageGen으로 새로 생성한 투명 PNG.
- 파일: `house-exterior.png`. 기존 캐릭터/타일 아틀라스는 수정하지 않았다.
- 제작 프롬프트: top-down 2D pixel-art RPG용 한국 주택 1채, 정면에 가까운 투영, 청회색 경사지붕·처마, 밝은 회벽, 하단 벽돌 기단, 커튼 창문 두 개, 왼쪽 현관과 차양·현관등, 창가 화분. 배경·문자·인물 없이 건물 전체를 투명 배경에 배치.
- 실제 출력은 고해상도 일러스트형 스프라이트이며 48px 규격 타일 시트가 아니다. `map.js`에서 별도 이미지로 5×5칸에 표시한다.
- 배치: 왼쪽 위 (41,13), 현관 트리거 (42,18). 출입/충돌 판정은 `world.js`에서 관리한다.
- 이미지 로딩 실패 시 기존 벽 타일로 표시한다. 현관 타일은 새 출입 좌표를 따른다.
- 확인: PNG 육안 확인, JS 구문 검사, 교실→침대 길찾기 도달 확인.
- 미확인: 실제 브라우저 합성 화면 및 터치 플레이. 현재 환경에서 Edge가 DOM을 반환하지 않고 내장 브라우저는 로컬 서버 연결에 실패했다.
