# 주인공 그림체 시안 v3

2026-10-18. 남녀 주인공의 맵 정면 시안과 대화용 초상화를 제작했다. 기존 landing/hero-boy.png, hero-girl.png를 인물 정체성 참고로 사용한다.

| 파일 | 용도 |
|---|---|
| boy-map-front.png | 남학생 주인공의 3등신 정면 기본 자세, 고해상도 설계 원본 |
| girl-map-front.png | 여학생 주인공의 3등신 정면 기본 자세, 고해상도 설계 원본 |
| boy-portrait.png | 남학생 주인공의 대화용 반신 초상화, 기본 표정 |
| girl-portrait.png | 여학생 주인공의 대화용 반신 초상화, 기본 표정 |

## 디자인 기준

- 남학생: 짧은 남색 머리, 파란 눈. 여학생: 갈색 포니테일, 파란 머리끈, 호박색 눈.
- 공통: 파란 후드, 노란 가방, 짙은 바지, 파랑·흰색 운동화. 기존 랜딩과 동일 인물로 인식될 것.
- 맵용은 손에 폰을 들지 않는 정면 기본 자세. 얼굴·머리·옷을 큰 색면으로 읽히게 한다.
- 초상화는 자연스러운 청소년 비율, 눈높이의 반신 구도와 차분한 기본 표정. 맵용 3등신 비율을 그대로 늘리지 않는다.

## 이번 납품 범위

**고해상도 디자인 시안 4장이다.** 48×72 정밀 픽셀 프레임이나 4방향 걷기 시트가 아니다. 현재 게임/랜딩 이미지는 교체하지 않았다. preview.html의 48×72 및 96×144 샘플은 가독성 확인을 위한 런타임 축소 표시이며 최종 픽셀 정리 결과가 아니다.

## 후속 제작 및 Claude Code 주의사항

1. 이 시안으로 그림체를 확인한 뒤 같은 얼굴·체형·옷을 유지하며 아래/왼쪽/오른쪽/위 방향과 걷기 프레임을 제작한다. 새 프레임마다 다른 인물처럼 재해석하지 않는다.
2. 현재 맵 계약은 48×72 프레임, 192×288 시트, 가로 4프레임·세로 아래/왼/오/위이다. 단일 PNG를 기존 시트 파일명에 덮어쓰지 않는다. 프레임 기준점과 발바닥 높이를 먼저 통일한다.
3. 고해상도 시안을 무조건 축소하면 눈·후드끈 등이 뭉개질 수 있다. 실제 크기에서 얼굴·손·발을 단순화하고 확인한다. 프레임 크기 변경은 별도 구현 검토가 필요하다.
4. 초상화는 걷기 시트와 별도 로딩/스타일로 취급한다. 픽셀화 또는 palette.js 보정을 적용하지 않는다. 인물 이름과 대사는 이미지가 아니라 텍스트로 표시한다.
5. portrait를 사용할 때 알파 경계를 측정하고 머리·턱·어깨를 자르지 않게 배치한다. 모바일에서 초상화가 선택지나 본문을 덮지 않게 한다. 아래 샘플 UI는 구도 참고용이며 구현된 게임 화면이 아니다.
6. 기본 표정만 제작했다. 걱정·놀람·안도 등은 이후 같은 원본을 편집해 추가한다. 인물의 피부색·머리·나이·옷이 표정마다 바뀌지 않게 한다.
7. player_m/player_f 선택값은 기존 privacy 전용 설정에 따른다. 팀 공통 캐릭터 코드 매핑을 임의로 만들거나 ethicity.player를 덮어쓰지 않는다.
8. 다른 인물(하윤·서아·도현·민준·담임)의 초상화와 맵 시트는 이번 납품에 포함하지 않았다. 현재 다른 에이전트가 진행 중인 UI/맵 변경은 보존한다.

원본 PNG는 투명 배경으로 저장하며 기존 assets/sprites와 assets/landing은 보존한다. 이번 작업은 로컬 에셋 납품으로 push/배포하지 않는다.
