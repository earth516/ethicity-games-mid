## Claude Code 적용 안내

- 게임 연결은 아직 하지 않았다. 위 스토리 ID를 별도 초상화 매핑에 연결한다. 기존 걷기 시트를 덮어쓰지 않는다.
- 이미지에 이름·대사를 넣지 않았다. 이름과 대사는 기존 텍스트로 유지한다.
- `object-fit: contain`으로 전체 머리·어깨를 보존한다. 파일별 알파 경계는 friends-metadata.json에서 확인한다. 이미지 크기와 실제 인물 영역은 다르다.
- palette.js 보정과 image-rendering: pixelated를 적용하지 않는다.
- 모바일에서 초상화가 대사·선택지·진행 버튼을 가리지 않게 배치한다. 이미지 로딩 실패 시 기존 인물 이름·이니셜 표시를 유지한다.
- 기본 표정만 있으므로 심각한 사건에서 이를 행복·안도 표정으로 해석하지 않는다. 걱정·놀람·안도 등 장면별 표정은 후속 제작 대상이다.
- friends-preview.html은 에셋 비교 화면이며 실제 게임 UI가 아니다. check-friends.cjs는 격리된 브라우저에서 로딩·알파를 검사하고 미리보기를 저장한다.
- 기존 공통 플레이어 정보, 저장 규격, 맵·대사 코드는 변경하지 않는다.
